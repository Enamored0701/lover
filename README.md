# PREVIA

独立的双人私人页刊。个人内容只存于当前浏览器的 IndexedDB；梦角行为由可编辑字卡与本地随机时间驱动，不使用 AI。

## 本地运行
需要 Node.js 22.12+（建议 Node.js 24）与 npm 11+。如果使用旧版 npm，请先运行 `npm install -g npm@11`。

```sh
npm ci
npm run dev
```

## 部署
将本文件夹全部源码上传到 GitHub 仓库，连接支持 Node.js 网站的托管服务（如 Render、Railway 或自己的服务器）。

- 构建命令：`npm ci && npm run build`
- 启动命令：`npm start`
- 默认服务端口由 `PORT` 环境变量配置。
- 为通知和浏览器音频功能开启 HTTPS。
- 本站含网易云歌单和歌词的服务端请求，不能仅部署到 GitHub Pages 等纯静态托管。
- 无需配置数据库或平台 API 密钥；MUSIC_U 由本人在页面中输入，只随单次请求使用，不写入存储。会员歌曲、第三方接口和地区限制仍可能影响播放。

## 内容备份与隐私
源码包包含所有程序、默认图片、网站图标、用户提供的默认字体和测试，不包含浏览器内的私人日记、头像替换、聊天历史或 MUSIC_U。迁移设备或网址前，在「我们 → 设置 → 数据」导出备份，部署后再导入。
源码部署本身不提供访问密码；如需只有本人访问，使用托管服务的访问保护。不要把 MUSIC_U 或私人备份上传到 GitHub。
本机通知和后台辅助音频依赖浏览器支持，不能保证锁屏后持续运行；远程推送尚未配置。
用户提供字体的使用与再分发授权由使用者确认。

## 添加到主屏幕 / 安装
部署到 HTTPS 网站后，iPhone 使用 Safari → 分享 → 添加到主屏幕；Android 在支持的浏览器菜单选择安装应用或添加到主屏幕。应用名称为 PREVIA。完整包包含 192/512 像素图标、适应安卓遮罩的 512 像素图标、180 像素 Apple 图标及 manifest.webmanifest。浏览器是否展示安装按钮由系统决定。无需服务工作线程，不承诺离线使用或后台持续运行。

请将网站部署在域名根路径（/），不要部署为 GitHub Pages 子目录。上传仓库的是源码，不是私人数据；安装后仍需在同一网站导入个人备份。

## 新增字卡
俄语在“字卡库 → 俄语”中导入，每行或 JSON 字符串使用 `Дорогой【亲爱的】`，中文翻译写在末尾的【】中。经期字卡在“字卡库 → 经期”内按 经期中、预测经期、预测排卵期、易孕期 分组；日期占位符为 {date}。经期预测只是日历估算，不用于避孕或诊断。主动来电和拍一拍各为每个合适时间窗 5% 概率，其他普通互动抽取更高概率；没有 AI 或真实对方在线参与。
